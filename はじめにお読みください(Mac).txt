クイック翻訳  かんたん説明書(Mac 用)
=============================================

Windows の方は「はじめにお読みください(Windows).txt」をお読みください。

Web ページの文章を選ぶだけで、すぐ下に翻訳が出る Chrome の拡張機能です。
翻訳は自分の Mac の中で行うので、初期設定では文章がネットに送られることはありません。料金もかかりません。
(Apple シリコンの Mac で動作を確認しています)


■ 準備(最初の 1 回だけ)
----------------------------------

【1】拡張機能を Chrome に入れる

  ● Chrome ウェブストアから入れる場合
      ストアの「クイック翻訳」のページで「Chrome に追加」を押します。

  ● zip で受け取った場合
    (1) zip をダブルクリックして展開し、
        できた「plamo-translate-ext」フォルダを、消さない場所(「書類」フォルダなど)に置きます。
        ※ このフォルダを消したり移動したりすると、拡張機能が動かなくなります。
    (2) Chrome のアドレス欄に chrome://extensions と入力して開きます。
    (3) 右上の「デベロッパー モード」をオンにします。
    (4) 「パッケージ化されていない拡張機能を読み込む」を押し、
        「plamo-translate-ext」フォルダを選びます。

  設定画面が自動で開けば、拡張機能の読み込みは完了です。
  まだ翻訳はできないので、続けて【2】へ進んでください。


【2】翻訳サーバーを自動で起動するようにする(おすすめ)

  「自動起動を設定する.command」をダブルクリックし、番号を入力して Enter を押します。
  翻訳エンジン(llama.cpp)が入っていないときは、自動でダウンロードします。
  ※ ストアから入れた場合は、先に「翻訳サーバーのセット」をダウンロードして展開してください。
      https://github.com/DelacrowLab/plamo-select-translate/releases/latest
      の一覧から「plamo-translate-server-」で始まる zip を選びます
      (「plamo-translate-ext-」で始まる zip は選びません)。

    1. 0.8B のみ   … 速くて軽い(ダウンロード 約 0.6 GB) ※おすすめ
    2. 0.8B と 2B  … 拡張機能の設定画面で 0.8B / 2B / 使い分け を自由に切り替えられる(ダウンロード 約 2.4 GB)

  何も入力せずに Enter を押すと 1(0.8B のみ)になります。迷ったら 1 で十分です。
  2B も試したくなったら、あとでもう一度実行して 2 を選べば追加できます。

  これで今すぐ翻訳サーバーが裏で起動し、次回からは Mac にログインするたびに自動で起動します。
  ・初回だけ、モデルのダウンロードに数分かかります。
  ・しばらく翻訳しないと、モデルをメモリから下ろします(0.8B は 30 分、2B は 10 分)。
    次に翻訳したときに自動で戻ります。このときだけ数秒かかります。
  ・翻訳サーバーのセットのフォルダは、設定後に移動・削除してもかまいません
    (ただし zip で拡張機能を入れた場合、拡張機能のフォルダは消さないでください)。

  ▼「開けません」「開発元を検証できません」と出て、ダブルクリックで開けないとき
    Mac を守るための確認です。次のどちらかで開けます。
    ・「システム設定」→「プライバシーとセキュリティ」を開き、画面の下の方にある「このまま開く」を押す
      (macOS のバージョンによっては、ファイルを右クリック →「開く」でも開けます)
    ・ターミナルで次のようにする(確実な方法)
      (1)「cd 」(cd のあとに空白)と入力し、展開したフォルダをターミナルにドラッグして Enter を押す
      (2) 次の 1 行を貼り付けて Enter を押す

            bash start-server.sh --install

  ※ 自動起動を使わない場合は、使うたびに「翻訳サーバーを起動する.command」を開いてください。
     開いたウィンドウを閉じるとサーバーも止まります。


【3】動作を確かめる

  (1) Chrome 右上のパズルのアイコン →「クイック翻訳」を押して設定画面を開き、
      「接続テスト」で「成功」と出るか確かめます。
      (モデルのダウンロード中は失敗します。数分待ってからもう一度押してください)
  (2) 新しいタブで Web ページを開くか、すでに開いているページを再読み込みします。
      拡張機能を入れる前から開いていたタブでは、再読み込みするまで翻訳されません。
  (3) 英語の文章を選択します。すぐ下に翻訳が出れば完了です。
      ※ Chrome ウェブストアのページ、chrome:// で始まるページでは使えません。
      PDF は、文章を選んでから右クリック →「クイック翻訳で翻訳」で翻訳します。


■ 使い方
----------------------------------

  Chrome で文章を選択すると、すぐ下に翻訳が表示されます。
  ・右クリック →「クイック翻訳で翻訳」や、option + T キーでも翻訳できます
    (キーは chrome://extensions/shortcuts で変更できます)。
  ・数字だけを選んだときは翻訳しません。
  ・日本語以外は何でも翻訳します。翻訳したくない言語は、設定画面の「翻訳する言語」でチェックを外します。
  ・esc キーか、ほかの場所をクリックすると閉じます。

  使うモデルや翻訳先の言語は、設定画面で変えられます。変えなくても使えます。


■ うまく動かないとき
----------------------------------

・「翻訳サーバーに接続できません」と出る、「接続テスト」が失敗する
    → 設定した直後や Mac の起動直後は、モデルの準備に時間がかかります。数分待ってください。
    → 待っても直らないときは、「自動起動を設定する.command」をもう一度開いてください。

・「llama-server が見つかりません」と出る
    → インターネットにつながっているか確かめて、「自動起動を設定する.command」をもう一度開いてください。

・「ポート 8080 はすでに使われています」と出る
    → 自動起動で翻訳サーバーがすでに動いています。「翻訳サーバーを起動する.command」を開く必要はありません。

・2B を選んでも「0.8B で翻訳しました」と出る
    → 「自動起動を設定する.command」をもう一度開き、2(0.8B と 2B)を選んでください。

・翻訳が出ない、反応しない
    → ページを再読み込みしてください。
    → 設定画面の「テキスト選択時に自動で翻訳する」がオフになっていないか確かめてください。

・翻訳サーバーが起動しない理由を調べたいとき
    → ~/Library/Application Support/PLaMoQuickTranslate にある記録(ログ)に理由が残ります。


■ やめるとき
----------------------------------

(1) 「自動起動を解除する.command」をダブルクリックします(裏で動いている翻訳サーバーも止まります)。
(2) chrome://extensions で「クイック翻訳」の「削除」を押します。
(3) 翻訳エンジンも消す場合は、~/Library/Application Support/PLaMoQuickTranslate を削除します
    (Homebrew で入れた場合は、ターミナルで brew uninstall llama.cpp を実行します)。
(4) ダウンロードされた翻訳モデルは、次のフォルダにあります。不要なら削除してください。
      ~/.cache/huggingface/hub/models--pfnet--plamo-3-translate-0.8b-GGUF
      ~/.cache/huggingface/hub/models--pfnet--plamo-3-translate-2b-GGUF


その他(モデルのライセンス・プライバシーなど)は「はじめにお読みください(Windows).txt」の後半を参照してください。
