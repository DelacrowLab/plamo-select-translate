PLaMo クイック翻訳 - Mac での使い方
====================================

拡張機能そのものは Windows と同じです。違うのは翻訳サーバーの入れ方と起動のしかただけです。
(Apple シリコンの Mac で動作を確認しています)


1. llama.cpp を入れる
---------------------
  Homebrew(https://brew.sh)を入れたうえで、ターミナルで次を実行します。

    brew install llama.cpp


2. 拡張機能を入れる
-------------------
  Chrome ウェブストアから入れるか、zip を展開したフォルダを次の手順で読み込みます。
  (読み込んだフォルダは移動・削除しないでください)

    1) Chrome のアドレス欄に chrome://extensions と入力して開く
    2) 右上の「デベロッパー モード」をオンにする
    3) 「パッケージ化されていない拡張機能を読み込む」で、manifest.json があるフォルダを選ぶ


3. 翻訳サーバーを自動起動する
-----------------------------
  「自動起動を設定する.command」をダブルクリックし、番号を入力して Enter を押します。

    1. 0.8B のみ   … 速くて軽い ※おすすめ
    2. 0.8B と 2B  … 設定画面で 0.8B / 2B / 使い分け を切り替えられる

  これで、Mac にログインするたびに翻訳サーバーが裏で自動的に起動します。今回もすぐ起動します。
  初回はモデルのダウンロードに数分かかります。

  ※ 初めてダブルクリックしたとき「開発元を検証できないため開けません」と出た場合は、
     ファイルを右クリック(control + クリック)→「開く」→「開く」を選んでください。
     それでも開けない場合は、ターミナルでこのフォルダに移動して次を実行します。
       bash start-server.sh --install
  ※ 自動起動を使わない場合は、使うたびに「翻訳サーバーを起動する.command」を開き、
     ウィンドウを開いたままにしてください。
  ※ 登録内容は ~/Library/LaunchAgents/io.github.delacrowlab.plamo-quick-translate.*.plist、
     記録(ログ)は ~/Library/Application Support/PLaMoQuickTranslate にあります。
  ※ Mac では GPU(Metal)を使って翻訳するため、Windows より速く動きます。


4. 確認する
-----------
  Chrome の拡張機能のアイコン(または chrome://extensions の「詳細」→「拡張機能のオプション」)から
  設定画面を開き、「接続テスト」を押します。
  あとは Web ページで英語などの文章を選ぶと、すぐ下に翻訳が表示されます。
  ショートカットは option + T です(chrome://extensions/shortcuts で変更できます)。


やめるとき
----------
  「自動起動を解除する.command」をダブルクリックすると、自動起動の登録を消し、
  裏で動いている翻訳サーバーを止めます。
  llama.cpp も消す場合は brew uninstall llama.cpp、
  ダウンロードしたモデルも消す場合は ~/Library/Caches/llama.cpp を削除してください。

その他(モデルのライセンス・プライバシーなど)は「はじめにお読みください.txt」を参照してください。
