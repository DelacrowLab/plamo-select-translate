クイック翻訳  かんたん説明書(Windows 用)
=================================================

Mac の方は「はじめにお読みください(Mac).txt」をお読みください。

Web ページの文章を選ぶだけで、すぐ下に翻訳が出る Chrome の拡張機能です。
翻訳は自分の PC の中で行うので、初期設定では文章がネットに送られることはありません。料金もかかりません。

・日本語以外を選ぶと → 日本語に翻訳(翻訳したくない言語は、設定画面で外せます)
・日本語を選ぶと   → 何もしません(設定で「英語に翻訳」などに変えられます)

最新版・問い合わせ: https://github.com/DelacrowLab/plamo-select-translate


■ 準備(最初の 1 回だけ)
----------------------------------

【1】拡張機能を Chrome に入れる

  ● Chrome ウェブストアから入れる場合
      ストアの「クイック翻訳」のページで「Chrome に追加」を押すだけです。

  ● zip で受け取った場合
    (1) zip を展開(右クリック →「すべて展開」)し、
        できた「plamo-translate-ext」フォルダを、消さない場所に置きます。
        ※ このフォルダを消したり移動したりすると、拡張機能が動かなくなります。
    (2) Chrome のアドレス欄に chrome://extensions と入力して開きます。
    (3) 右上の「デベロッパー モード」をオンにします。
    (4) 「パッケージ化されていない拡張機能を読み込む」を押し、
        「plamo-translate-ext」フォルダを選びます。

  設定画面が自動で開けば、拡張機能の読み込みは完了です。
  まだ翻訳はできないので、続けて【2】へ進んでください。


【2】翻訳サーバーを自動で起動するようにする(おすすめ)

  「自動起動を設定する.bat」をダブルクリックし、番号を入力して Enter を押します。
  翻訳エンジン(llama.cpp)が入っていないときは、自動でインストールします。
  ※ ストアから入れた場合は、先に「翻訳サーバーのセット」を下のページからダウンロードして展開してください。
      https://github.com/DelacrowLab/plamo-select-translate/releases/latest
      一覧から「plamo-translate-server-」で始まる zip を選びます(「plamo-translate-ext-」で始まる zip は選びません)。

    1. 0.8B のみ  … 速くて軽い(ダウンロード 約 0.6 GB) ※おすすめ
    2. 0.8B と 2B … 拡張機能の設定画面で 0.8B / 2B / 使い分け を自由に切り替えられる(ダウンロード 約 2.4 GB)

  何も入力せずに Enter を押すと 1(0.8B のみ)になります。迷ったら 1 で十分です。
  2B も試したくなったら、あとでもう一度「自動起動を設定する.bat」を実行して 2 を選べば追加できます。

  これで今すぐ翻訳サーバーが裏で起動し、次回からは PC にサインインするたびに自動で起動します。ウィンドウは出ません。
  ・しばらく翻訳しないと、モデルをメモリから下ろします(0.8B は 30 分、2B は 10 分)。
    使っていないあいだのメモリは 1 つあたり約 50 MB です(翻訳中は 0.8B が約 1.1 GB、2B が約 3.7 GB)。
    次に翻訳したときに自動で戻ります。このときだけ数秒かかります。
  ・初回だけ、モデルのダウンロードに数分かかります。
  ・自動起動に必要なファイルは %LOCALAPPDATA%\PLaMoSelectTranslate にコピーされるので、
    翻訳サーバーのセットのフォルダは、設定後に移動・削除してもかまいません
    (ただし zip で拡張機能を入れた場合、拡張機能のフォルダは消さないでください)。
  ・自動起動の記録は %LOCALAPPDATA%\PLaMoSelectTranslate\autostart.log に残ります。
    翻訳サーバーが起動しないときは、このファイルをメモ帳で開くと理由がわかることがあります。

  ★ 2(0.8B と 2B)を選んだときは、拡張機能の設定画面の「使うモデル」で
     0.8B / 2B / 使い分け を選んで「保存」するだけで切り替わります(初期設定は 0.8B)。
     使い分けでは、選んだ文字が 2 単語以下なら 0.8B、3 単語以上なら 2B で翻訳します。
     (日本語も単語ごとに数えます。例:「機械翻訳」は 2 単語。境目の単語数は設定画面で変えられます)

  ※ 自動起動を使わない場合は、使うたびに「start-server.bat」をダブルクリックしてください。
     開いたウィンドウを閉じるとサーバーも止まります。


【3】動作を確かめる

  (1) Chrome 右上のパズルのアイコン →「クイック翻訳」を押して設定画面を開き、
      「接続テスト」で「成功」と出るか確かめてください。
      (モデルのダウンロード中は失敗します。数分待ってからもう一度押してください)
  (2) 新しいタブで Web ページを開くか、すでに開いているページを再読み込みします。
      拡張機能を入れる前から開いていたタブでは、再読み込みするまで翻訳されません。
  (3) 英語の文章を選択します。すぐ下に翻訳が出れば完了です。
      ※ Chrome ウェブストアのページ、chrome:// で始まるページでは使えません。
      PDF は、文章を選んでから右クリック →「クイック翻訳で翻訳」で翻訳します。


■ 使い方
----------------------------------

  Chrome で文章を選択すると、すぐ下に翻訳が表示されます。
  ・右クリック →「クイック翻訳で翻訳」や、Alt + T キーでも翻訳できます。
  ・入力欄の中で選んだ文章も翻訳できます。
  ・数字だけを選んだときは翻訳しません。
  ・Esc キーか、ほかの場所をクリックすると閉じます。


■ 設定を変えたいとき
----------------------------------

Chrome 右上のパズルのアイコン →「クイック翻訳」で設定画面が開きます。
使うモデル(0.8B / 2B / 使い分け)、翻訳先の言語、です・ます調/だ・である調、
選択したらすぐ翻訳するかどうか、などを変えられます。

2B を選んでも「2B のサーバーに接続できないため、0.8B で翻訳しました」と出る場合は、
翻訳サーバーが「0.8B のみ」で起動しています。
「自動起動を設定する.bat」をもう一度実行して、2(0.8B と 2B)を選んでください。


■ 1.2.x(「PLaMo 選択翻訳」)から更新した人へ
----------------------------------

・新しい「翻訳サーバーのセット」の「自動起動を設定する.bat」を、もう一度実行してください。
  自動起動は登録したときのスクリプトのコピーで動くため、実行し直すまでは古い設定のまま動きます。
  (1.2.x で「2B のみ」を選んでいた場合、古い設定では 2B がポート 8080 で動いているため、
   「使うモデル」で 0.8B を選んでいても 2B で翻訳されます)
・古い名前の自動起動(「PLaMo 選択翻訳サーバー」)は、実行し直したときに自動で消えます。
・設定画面で保存したことがある人は、「選択テキストが日本語だったときの翻訳先」が以前の「英語」のまま残っています。
  1.3.0 の初期設定(日本語の文章は翻訳しない)にしたい場合は、「なし(翻訳しない)」を選んで保存してください。
・1.2.x で「使い分け」にしていた人は、「使うモデル」が自動で「使い分け」になります。


■ うまく動かないとき
----------------------------------

・「翻訳サーバーに接続できません」と出る
    → 自動起動を設定した直後や PC の起動直後は、モデルの準備に時間がかかります(初回はダウンロードで数分)。少し待ってください。
    → 待っても直らないときは、「自動起動を設定する.bat」をもう一度実行してください。
    → 自動起動を設定していない場合は、start-server.bat を開いてください。

・「llama-server が見つかりません」と出る
    → インターネットにつながっているか確かめて、「自動起動を設定する.bat」をもう一度実行してください。

・「ポート 8080 はすでに使われています」と出る
    → 自動起動で翻訳サーバーがすでに動いています。start-server.bat を開く必要はありません。

・翻訳結果が「&&&&…」のように壊れる
    → 自分でコマンドを打って起動していませんか? 自動起動か start-server.bat を使ってください
      (CPU だけで動かす設定になっています)。

・翻訳が出ない、反応しない
    → 拡張機能を入れる前から開いていたタブでは動きません。ページを再読み込みしてください。
    → Chrome のウェブストアのページ、chrome:// で始まるページでは使えません。
      PDF は、文章を選んでから右クリック →「クイック翻訳で翻訳」で翻訳します。

・ブラウザの拡張機能の「エラー」に記録が残っている
    → 拡張機能を入れ直したり更新したりする前のタブで起きた記録の場合があります。
      「すべて削除」で消してから、タブを再読み込みして様子を見てください。

・Chrome の起動時に「デベロッパー モードの拡張機能を無効にする」などと出る(zip で入れた場合)
    → ストアを通さずに入れた拡張機能のための表示です。そのまま閉じてかまいません。


■ アンインストール
----------------------------------

(1) 「自動起動を解除する.bat」をダブルクリックします(自動起動を設定した場合)。
    裏で動いている翻訳サーバーも止まります。
(2) chrome://extensions で「クイック翻訳」の「削除」を押します。
(3) 翻訳エンジンも消す場合は、ターミナルで次の 1 行を実行します。
      winget uninstall llama.cpp
(4) ダウンロードされた翻訳モデルは、次のフォルダにあります。不要なら削除してください。
      %USERPROFILE%\.cache\huggingface\hub\models--pfnet--plamo-3-translate-0.8b-GGUF (0.8B、約 0.6 GB)
      %USERPROFILE%\.cache\huggingface\hub\models--pfnet--plamo-3-translate-2b-GGUF   (2B、約 1.8 GB)
    自動起動の記録(ログ)は %LOCALAPPDATA%\PLaMoSelectTranslate にあります。これも削除してかまいません。


■ プライバシーと安全について
----------------------------------

・初期設定では、選択した文章とページタイトルは、PC の中の翻訳サーバーにだけ送られます。
  設定画面で PC 以外のサーバー(https:// のみ)を指定した場合は、そのサーバーに送られます。
・翻訳サーバーは同じ PC からしか接続できず、閲覧中の Web ページが勝手に使えないように設定しています。
・翻訳した文章や結果は保存しません。
・start-server.bat などは、同じフォルダの start-server.ps1(PowerShell のスクリプト)を実行します。
  中身はメモ帳で確認できます。
