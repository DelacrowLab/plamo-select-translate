クイック翻訳

ページ上のテキストを選択すると、PC 上で動かす PLaMo 3 Translate がすぐに翻訳します。初期設定では、翻訳する文章は PC の外に送られません(PC 以外のサーバーを設定した場合は、選択した文章とページタイトルがそのサーバーに送られます)。

はじめに: 翻訳サーバーの準備

翻訳するには、最初の 1 回だけ次の準備が必要です(すでに翻訳できている場合は読み飛ばしてください)。

お使いのパソコン:
  1. 「翻訳サーバーのセット」を用意します。ダウンロードのページ(GitHub)の一覧から、plamo-translate-server- で始まる zip を選びます(plamo-translate-ext- で始まる zip は選びません)。ダウンロードしたら展開します。zip で拡張機能を受け取った人は、同じフォルダに入っているので、この手順は不要です。
  2. セットの中の 自動起動を設定する.bat をダブルクリックし、「1. 0.8B のみ」か「2. 0.8B と 2B」を選びます。
    以後はPC にサインインするたびに、翻訳サーバーが裏で自動的に起動します(今回もすぐ起動します)。翻訳エンジン(llama.cpp)が入っていないときは、自動でインストールします。 迷ったら 1 で十分です。自動起動しない場合は、使うたびに start-server.bat をダブルクリックして起動します。
  3. すぐ下の「接続テスト」を押します。「成功」と出れば準備完了です。初回はダウンロードに数分かかるので、失敗したら少し待ってからもう一度押してください。
  1. 「翻訳サーバーのセット」を用意します。ダウンロードのページ(GitHub)の一覧から、plamo-translate-server- で始まる zip を選びます(plamo-translate-ext- で始まる zip は選びません)。ダウンロードしたら展開します。zip で拡張機能を受け取った人は、同じフォルダに入っているので、この手順は不要です。
  2. セットの中の 自動起動を設定する.command をダブルクリックし、「1. 0.8B のみ」か「2. 0.8B と 2B」を選びます。
    以後はMac にログインするたびに、翻訳サーバーが裏で自動的に起動します(今回もすぐ起動します)。翻訳エンジン(llama.cpp)が入っていないときは、自動でインストールします。 迷ったら 1 で十分です。自動起動しない場合は、使うたびに 翻訳サーバーを起動する.command をダブルクリックして起動します。 開けないと表示されたときは、「システム設定」→「プライバシーとセキュリティ」の「このまま開く」を押します(詳しくは「はじめにお読みください(Mac).txt」)。
  3. すぐ下の「接続テスト」を押します。「成功」と出れば準備完了です。初回はダウンロードに数分かかるので、失敗したら少し待ってからもう一度押してください。
「成功」と出たら、新しいタブで Web ページを開くか、開いていたページを再読み込みしてから、英語の文章を選択してください。PDF は、文章を選んでから右クリック →「クイック翻訳で翻訳」で翻訳します(Chrome ウェブストアと chrome:// で始まるページでは使えません)。
Linux や、ターミナルから自分で起動する場合 llama.cpp を入れてから、次のコマンドで 0.8B を起動します。2B も使う場合は、別のターミナルで 0.8b を 2b に、8080 を 8081 に変えたコマンドも起動します。 
llama-server -hf pfnet/plamo-3-translate-0.8b-GGUF:Q4_K_M --host 127.0.0.1 --port 8080 --api-key plamo-select-translate --cors-origins https://plamo-select-translate.invalid --no-webui --no-slots -ngl 0 --device none -c 8192 --sleep-idle-seconds 1800
--api-key(公開の合言葉)と --cors-origins(どのページにも許可しない値)は、閲覧中の Web ページが PC 上の翻訳サーバーを勝手に使えないようにするための設定です。GPU を使う場合は -ngl 0 --device none を外してください(一部の GPU では翻訳結果が壊れることがあります)。

初めての方は、ここから下の設定は変更しなくても使えます。

使うモデル

2B と使い分けは、翻訳サーバーを「0.8B と 2B」で起動しているときに使えます。2B のサーバーが動いていないときは 0.8B で翻訳し、翻訳パネルにその旨を表示します。
この単語数以下なら 0.8B、それより多ければ 2B で翻訳します。日本語や中国語も単語ごとに数えます(例: 「機械翻訳」は 2 単語、「今日はいい天気ですね」は 6 単語)。
詳細設定(自分でサーバーを用意する場合) 翻訳サーバーのセットで起動した場合は変更不要です(0.8B は http://127.0.0.1:8080/v1、2B は http://127.0.0.1:8081/v1)。PC 以外のサーバーは https:// の URL のみ指定できます。指定すると、そのサーバーへのアクセス許可を求められ、翻訳時には選択した文章(と、オンの場合はページタイトル)がそのサーバーに送られます。 vLLM では --served-model-name に指定した名前。llama-server では変更不要です。 翻訳サーバーのセットで起動したサーバーでは不要です(空欄のままにしてください)。入力した値はこの PC の Chrome にだけ保存され、ほかの端末には同期されません。

翻訳設定

チェックを入れた言語の文章だけを翻訳します。初期設定は英語だけです。短い語句で言語を判定できないときは、同じ文字を使う言語にチェックがあれば翻訳します。 翻訳先が日本語のときだけ使います。「なし」にすると、日本語の文章を選んでも翻訳しません(文字を選んだだけのときはパネルも出ません。右クリックや Alt+T(Mac は option+T)で翻訳しようとしたときは、翻訳しない設定であることを表示します)。 人名、企業名、一般的でない化学物質名など。大文字・小文字は区別しません。多くの場合はそのまま残りますが、必ず残るとは限りません。
人名や企業名を自動で残します。Paris のように普段はカタカナで訳す語も原語のまま残り、文頭の語は対象外です。
オフの場合は、右クリックメニューの「クイック翻訳で翻訳」か Alt+T(Mac は option+T)で翻訳します。
